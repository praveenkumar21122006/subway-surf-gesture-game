Troubleshooting
  • Open via http://localhost:8000, not file:// — camera is blocked on file URLs.
  • Allow camera permission in the browser (click the lock/camera icon in the address bar).
  • Close Zoom/Teams/Camera app — only one app can use the camera at a time.
  • Windows: Settings → Privacy & security → Camera → turn Camera access ON.
  • Keep one hand centered, good lighting, plain background.
  • If tracking is jittery, lower swipe sensitivity (smaller = more sensitive).
